# Green-chemistry
# 🧪 NADES-ML: Interactive Machine Learning Workbench
### Natural Deep Eutectic Solvents & Organometallic Drug Discovery

🎯 What This Notebook Does:
* Custom Data Inpu - Add your own NADES systems and organometallic compounds
* Interactive UI - Gradio-powered interface similar to a web application
* 15+ ML Models - Train and compare models with one click
* Real-time Predictions - Predict properties for any NADES-drug combination
* Explainability - SHAP & LIME analysis for model interpretation
* Export Results - Download predictions, models, and reports

🚀 How to Use:
1. Run all cells in order (`Runtime` → `Run all`)
2. Scroll down to find the Interactive Dashboard
3. Use tabs to navigate between Data, Training, Prediction, and Analysis
4. Upload your own CSV data or manually add entries
5. Train models and make predictions!

⚡ GPU Recommended:
Go to `Runtime` → `Change runtime type` → Select **T4 GPU** for faster training.
